# End-to-End Intrusion Investigation

## Objective

This project simulates a multi-stage attack against a Windows Server 2019 system and documents the investigation from a blue team perspective.

## Attack Flow

1. Reconnaissance
2. Initial Access
3. Execution
4. Persistence
5. Privilege Escalation
6. Incident Timeline
