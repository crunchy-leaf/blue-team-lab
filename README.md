# Blue Team Lab & Detection Projects

This repository documents a self-built Windows Active Directory lab focused on
blue team detection, log analysis, and incident response.

## Lab Environment
- Windows Server 2019 (Domain Controller)
- Kali Linux (Attacker)
- Active Directory (lab.local)
- Advanced Audit Policy enabled

## Skills Demonstrated
- Windows Event Log analysis
- Failed authentication detection (Event ID 4625)
- Privileged account monitoring
- Incident documentation
- Detection engineering fundamentals

## Notable Incidents
- Failed network authentication against domain user
- Credential abuse simulation and analysis

This repository reflects hands-on defensive security work.
